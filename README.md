# Red Bull Tracker 🐿⚽🐂

Red Bullの飲用記録を管理・集計するWebアプリです。

Pythonの学習を目的として開発し、Streamlitを使用したWeb画面、Supabaseを使用した認証・データ保存機能を実装しています。

## 主な機能

- メールアドレス・パスワードによるログイン
- Red Bullの飲用日・種類・本数・容量の記録
- 記録の公開・非公開設定
- 全期間・月別・年別の飲用本数集計
- 種類別・月間・年間の種類別集計
- 月間・年間で最も飲んだ種類の表示
- 公開記録のみを集計するデモモード
- PC・スマートフォンから利用可能

## 使用技術

- Python 3.12
- Streamlit
- Supabase
  - Database
  - Authentication
  - Row Level Security (RLS)
- Git / GitHub
- Streamlit Community Cloud

## 使い方

1. アプリを開く
2. メールアドレスとパスワードでログイン
3. 「記録する」タブから日付・本数・容量・種類を入力
4. 必要に応じて記録を公開・非公開に設定
5. 「記録を見る」タブから各種集計を確認

ログインせずに「デモで試す」を選択すると、公開設定された記録の集計を見ることができます。
